# 双图上传演示

保留单图上传，新增三种用户确认的双图模式：左右依次拖入、左右同时进入、同框先后替换。第二张照片独立选择或拖入，AI 结果图仍为可选的单张结果。

左右模式按各自原图比例布局。同框模式共用一个固定上传框，第二张落位后移除第一张。两张上传结束才启动转场，结果图在转场中替换整个组合。时长整体缩放，顺序模式音效分别对齐两次落位，同时模式使用同一个落位音效。透明 MOV 保留 alpha。

GUI 将 photo2、upload_mode 通过 /run_demo 的 opts 传入 DragDemo。缺第二张时在进入 busy 状态前报错。单图默认值不变，模式保存在设置中。标题预览展示最终布局，并非动画播放；完整动作以导出视频为准。

CLI: --photo2 path --upload-mode sequence|together|replace（默认 single）。

验证：tests/test_dual_demo.py 对四种模式分别实际导出 MP4/MOV，检查时长、左右颜色、替换结果及透明角像素；另以真实 Fotor 转场和结果图验证三种双图导出。HTTP 预览和缺图校验已独立检查。
